# Security reporting

If private vulnerability reporting is enabled, use **Security → Report a vulnerability** on GitHub. If it is unavailable, contact the project maintainers privately through an official Mango channel. Include the affected commit, component, and a summary. Keep credentials, personal data, and details that could enable misuse out of public issues.

This repository contains components at different maturity levels. A source directory or a passing local check does not establish that a component is deployed or supported. Confirm the supported release and deployment with the maintainers before relying on it.
